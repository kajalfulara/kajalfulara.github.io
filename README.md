# Kajal Fulara — Portfolio Website

Personal portfolio website for Kajal Fulara, an HR Operations and People Strategy professional. Built with React, TypeScript, Tailwind CSS, and Vite.

## Run locally

### Requirements

- Node.js 18 or later
- npm (included with Node.js)
- Git

### First-time setup

Clone the repository and install its dependencies:

```sh
git clone https://github.com/kajalfulara/kajalfulara.github.io.git
cd kajalfulara.github.io
npm install
```

Start the development server:

```sh
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173) in your browser. The server refreshes the page when you change source files. Stop it with `Ctrl+C`.

## Other commands

```sh
npm run build     # Create a production build in dist/
npm run preview   # Preview the production build locally
npm run lint      # Check the code with ESLint
```
